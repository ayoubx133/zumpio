About the game

Can you trace every line of the shape in a single stroke? You may pass each line only once. Find the right place to start and the right way to go. If you need help, the hint shows where to begin.

  • One finger, one line
  • Shapes that get trickier
  • Hint button for the start point
  • Lots of levels that get harder step by step
  • Unlock fun skins with the coins you earn
  • Bright colors, happy sounds and juicy effects
  • Made for Fire tablets, old and new models
  • Plays fully offline
